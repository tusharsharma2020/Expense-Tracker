# 💸 Expense Tracker Dashboard

A modern expense tracker built with **React + Tailwind CSS** featuring:

- ✅ Full Create/Read/Update/Delete (CRUD)
- 📊 Category-wise pie chart (Recharts)
- 🌙 Dark mode toggle
- 💾 LocalStorage persistence
- 🔍 Live Search + Sort
- 🍞 Toast notifications
- 💅 Beautiful glassmorphism UI
- 📱 Fully responsive layout

### 🛠️ Tech Stack
- React
- Tailwind CSS
- Recharts
- react-hot-toast
